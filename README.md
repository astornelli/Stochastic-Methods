# Stochastic-Methods
This repository is for the PHYS-475 Computational Physics Class at St. Mary's College of Maryland SP25. Our project was about exploring the uses of stochastic methods in physics. We first introduce the idea of discrete stochastic processes through random walk where our random walk is a bifurcating tree algorithm. We then motivate the idea of continuous stochastic methods through a particle simulation with Lennard-Jones potential in Langevin mechanics. In this simulation we track the mean squared displacement of our larger "Brownian" particle and plot over time to show it is indeed following a brownian motion. Since this simulation is in Langevin mechanics we added a damping factor and white gaussian noise to Lennard-Jones potential to get a more physically relevant model. We also implement a Kalman filter that can be used to filter out noise that is sufficiently Gaussian. This filter runs on synthetic data currently, but it could be applied to our Brownian simulation if it were sufficiently scaled (since the limiting behaviour of Brownian motion is provably Gaussian).
